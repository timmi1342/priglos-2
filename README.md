# Taklifnoma — Dilshodbek & Nilufarxon

Статическая копия страницы-приглашения
`https://taklif-link.uz/wedding/jahongir-umida` (шаблон «anor» / «Milliy»),
перенастроенная под другую пару: Dilshodbek & Nilufarxon, ресторан Sherbudin
(Бухара), 16.10.2026 11:00.

Оригинал — SPA на Vite + React: сервер отдаёт пустой `<div id="root">`,
данные приходят из `/api/weddings/url/jahongir-umida`, разметка собирается в
браузере. Здесь сохранён уже отрендеренный DOM плюс оригинальный CSS-бандл,
а поведение React-компонента переписано на ванильный JS — страница работает
без фреймворка, сборки и бэкенда.

## Что вошло

- конверт с печатью и его анимация открытия (скрытое состояние до клика);
- герой: орнамент, карнаи, имена с автоподгонкой ширины, фото пары;
- письмо-приглашение, календарь недели с сердцем на 16-м и временем 11:00, адрес и кнопки
  Яндекс/Google карт, обратный отсчёт;
- появление секций при прокрутке, анимации карнаев, музыкальный плеер
  с плавным нарастанием громкости и эквалайзером;
- два языка — UZ (по умолчанию) и RU. Английский убран.

## Что убрано

- форма подтверждения участия (RSVP);
- книга пожеланий (форма и список пожеланий гостей);
- блок «Закажите приглашение» со ссылками на Telegram/Instagram сервиса;
- строка под таймером («Sizni intiqlik bilan kutamiz» / «Мы ждем вас»);
- подпись сервиса внизу («Taklif tomonidan yaratilgan»).

Место, которое занимали последние две надписи, сохранено отступами в
`<style>` в `index.html`, чтобы цветок под таймером не съехал на цифры.

Галерея в оригинале пустая (фото не загружены), поэтому её нет и здесь.

## Отличия от оригинала

- имена, место, адрес (UZ — латиница, RU — по-русски) и ссылки на Яндекс и
  Google карты взяты из первого приглашения (`../index.html`);
- имена набраны курсивом Cormorant Garamond (в шаблоне Corinthia, в нём
  нет кириллицы) и переводятся: в RU — «Дильшодбек и Нилуфархон» на
  конверте, на главном экране, в подписи фото и в заголовке вкладки;
- в заголовке «Aziz va qadrdon insonimiz!» заглавная «A» набрана шрифтом
  Corinthia и увеличена: в Great Vibes она читается как «Cl». В русском
  заголовке шрифт не меняется;
- обратный отсчёт всегда по времени Узбекистана (UTC+5), а не по часовому
  поясу посетителя;
- время начала стоит под датами календаря (в шаблоне — третьей строкой
  адреса); сетка недели шире, а подписи дней и сердце ограничены по
  размеру, чтобы «SE / CHOR / PAY» и соседние даты не налезали друг на друга;
- декор не заходит на текст. Цветок стоит под таймером в обычном потоке
  страницы. Гранаты и карнаи уменьшаются скриптом (`fitOrnaments` в
  `index.html`) ровно настолько, чтобы между их рисунком и любым текстом
  было не меньше 16 px. Проверка идёт по маске непрозрачных пикселей
  картинки (`MASKS`) и повторяется при загрузке, смене языка и изменении
  размера окна. Если место совсем не остаётся, украшение скрывается.
  Проверено на ширинах 320–1920 px в обоих языках.

## Структура

```

                    только для справки, страницей не используется
```

## Анимации

| механика | как включается |
|---|---|
| открытие конверта | `.anx-intro` → `.is-opening` (клапаны складываются) → через 1 с `.is-gone` + `.anx--revealed` → через 1.9 с конверт удаляется |
| проявление страницы | `.anx--revealed .anx-sheet { opacity: 1 }` |
| карнаи | `@keyframes anx-horn-l-in / -r-in`, затем `anx-horn-l-pulse / -r-pulse` |
| reveal при скролле | `.anx-reveal` → `.is-visible`, задержки 0/90/180/270 мс |
| стрелка «вниз» | `@keyframes anx-bounce` |
| имена | `--line-fit` (0.68…1), пересчёт на resize и после загрузки шрифтов |
| обратный отсчёт | JS, цель `2026-10-16T11:00:00+05:00` |

## Локальный запуск

Любой статический сервер из этой папки, например:

```bash
npx serve .
```

## Деплой

Папка самодостаточна — на Vercel/Netlify указать её как корень проекта
(Root Directory), сборка не нужна. После деплоя замените в `index.html`
`og:image` / `twitter:image` на абсолютный адрес фото на вашем домене —
иначе превью ссылки в Telegram может не подтянуться.
